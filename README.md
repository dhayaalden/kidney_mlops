هذا المستودع يضم مشروعاً متكاملاً لتعلم الآلة والتعميق العميق (Deep Learning) باستخدام لغة بايثون ومكتبة TensorFlow، والمخصص 

لتحليل صور الأشعة والبيانات الطبية وتصنيف حالات الكلى (مثل الكشف عن الأورام، الحصوات، أو الالتهابات) بدقة عالية، مع تطبيق مفاهيم هندسة التعلم الآلي (MLOps).

## 📌 نبذة عن المشروع
يهدف هذا المشروع إلى بناء وتدريب نموذج شبكات عصرية لتصنيف الصور الطبية واكتشاف أمراض الكلى، مع توفير خط عمل (Pipeline) متكامل لإدارة البيانات، وتدريب النماذج، وتقييم الأداء بشكل آلي وموثوق.

## 🚀 المميزات الرئيسية

* **إدارة البيانات:** تنظيم ومعالجة مجموعات الصور وتقسيمها إلى مجلدات للتدريب (Train)، التحقق (Validation)، والاختبار (Test).
* **تدريب النموذج:** بناء وتدريب نموذج ذكاء اصطناعي متطور باستخدام TensorFlow و Keras.
* **التقييم والتحليل:** قياس دقة الأداء، استخراج مؤشرات الأداء، وتقييم النتائج على صور جديدة.
* **معمارية MLOps:** تطبيق معايير هندسية لتنظيم الكود وتسهيل نشر النموذج وإعادة إنتاجه.

## 🛠 التقنيات المستخدمة

* **Python** (بايثون)
* **TensorFlow / Keras**
* **NumPy / Matplotlib**
* **Jupyter Notebook** (ملفات العمل)
