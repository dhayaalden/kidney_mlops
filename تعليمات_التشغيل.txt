حزمة تشغيل نظام تصنيف صور الكلى

قبل التشغيل:
1. استخدم بيئة Python متوافقة مع requirements.txt.
2. ثبّت المكتبات باستخدام:
   python -m pip install -r requirements.txt

تشغيل الواجهة:
- شغّل الملف: تشغيل_التطبيق.bat
- أو نفّذ: python main.py web
- افتح المتصفح على: http://127.0.0.1:5000

محتويات الحزمة:
- كود التطبيق والواجهة.
- ملفات أوزان النموذج وملفات الإعدادات الموجودة داخل models/.
- متطلبات التشغيل.

لم تُضمّن مجموعة الصور الأصلية أو دفتر البحث أو سجل Git في هذه الحزمة.
تحتوي الحزمة على أوزان النموذج؛ لا تنشرها علنًا دون مراجعة صلاحيات المشاركة.

تنبيه:
هذه نسخة برمجية للتجربة والمراجعة. لا تُستخدم مخرجاتها لاتخاذ
قرار تشخيصي أو علاجي دون تحقق وتقييم سريري مستقلين.
